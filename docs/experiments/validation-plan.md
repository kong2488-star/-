## 1. 비교 조건

| 조건 ID | 패널 방향 | MPPT | 목적 |
| --- | --- | --- | --- |
| A | 고정 | P&O | 기본 비교 조건 |
| B | 추적 | P&O | A와 비교해 H1 평가 |
| C | 고정 | PSO + P&O Hybrid | A와 비교해 H2 평가 |
| D | 추적 | PSO + P&O Hybrid | B와 비교해 추가 MPPT 효과, A와 비교해 전체 효과 평가 |

고정 방향 MPPT 비교에서는 각도를 유지한다. 추적 효과 비교에서는 같은 MPPT와 동일한 패널 배열·부하를 사용한다. PSO 단독 모드는 알고리즘 진단에 사용하며, 필요하면 별도 비교 조건으로 추가한다.

현재 패널은 총 3개로 동일 배열 두 세트가 아니다. 세 패널을 하나의 배열로 사용하면 고정·추적 시험을 번갈아 수행한다. 패널 1개와 2개로 나눠 정격·면적이 다른 장치의 총발전량을 직접 비교하지 않는다.

6주 일정에서는 다음 순서로 증거를 확보한다. 본 실험 전에 실제 시험 시간과 환경을 고려해 유효 조합을 확정하며, 미수행 조건은 결과에서 명시한다.

1. A와 C: 무음영과 다중 피크가 확인된 대표 부분음영에서 MPPT 비교.
2. A와 B: 같은 P&O와 패널 배열에서 추적 효과 비교.
3. D: 대표 조건의 통합 동작과 보조 소비를 확인하고 해당 A·B·C 결과와 비교.
4. 위 비교가 확보된 뒤 추가 음영·초기값 조건을 확장.

## 2. 측정 경계와 에너지

기본 측정 경계는 다음과 같이 제안한다. 실제 모듈 단자와 전원 경로를 확인한 뒤 확정한다.

| 측정 | 제안 위치 | 해석 |
| --- | --- | --- |
| PV 입력 | 컨버터 앞 INA226 ① | 패널에서 추출한 전력; 실제 전압 측정 단자 명시 |
| 출력 | 컨버터 뒤 INA226 ② | 부하로 전달되는 전력 |
| 보조 소비 | 외부 보조전원과 장치 사이 INA226 ③ | 측정 경로에 포함된 서보·제어장치·전압 변환 소비 |

각 전력에 대해 실제 측정 시각을 사용해 에너지를 계산한다. 시각 단위가 초인 경우 사다리꼴 적분은 다음과 같다.

$$
E_{Wh} \approx \sum_k \frac{P_k + P_{k-1}}{2} \frac{t_k-t_{k-1}}{3600}
$$

외부 보조 소비를 모두 계측하고 출력 측정에 이미 차감되지 않은 구성에서는 다음 정의를 사용한다.

$$
E_{net}=E_{out}-E_{aux}
$$

고정형에도 포함되는 제어 소비가 있으므로 두 조건에 같은 경계를 적용한다. USB 전원 등 우회 공급 경로가 있으면 추가 측정하거나 결과의 제외 범위로 명시한다. 출력에 이미 반영된 소비를 다시 차감하지 않는다. PV 입력에서 출력으로의 손실에는 포함된 센서·배선 손실도 함께 설명한다.

## 3. 음영과 기준 전력 곡선

### 음영 조건

| 음영 ID | 계획 | 기록할 정보 |
| --- | --- | --- |
| S0 | 무음영 | 광원·날씨·패널 방향 |
| S1 | 한 패널 또는 구간 부분 차광 | 패널 ID, 가린 위치·면적·재료·거리 |
| S2 | 다른 강도 또는 두 구간 차광 | 구간별 조건과 배치 |

차광판과 고정 지그로 조건을 반복한다. S1·S2는 후보 시나리오이며 다중 피크 발생을 보장하지 않는다. 스윕으로 확인한 후 본 실험의 시나리오를 확정한다.

### 기준 스윕

1. 패널 각도와 음영을 고정하고 부하를 준비한다.
2. 검증된 운전 범위에서 명령을 순차 적용한다.
3. 각 지점에서 회로 안정화와 변경 이후의 새 센서 결과를 기다린다.
4. 일정한 평가 방식으로 전압·전류·평균 전력을 기록한다.
5. 실제 전압을 가로축으로 P–V 곡선을 작성하고 반복성을 확인한다.

기준 최대점은 측정한 범위·간격에서 얻은 최고점으로 정의한다. 기록 범위 밖의 더 높은 점을 배제하지 못하면 전역 최대점의 검증 범위를 제한해서 표현한다. 컨버터가 도달할 수 없는 동작점과 전체 PV 특성도 구분한다.

환경이 변하는 야외 스윕 한 번으로 이후 전 시간대의 이상적 최대전력을 확정하지 않는다. 정적 조건은 비교 전후 스윕으로 환경 변화를 확인하고, 크게 달라졌으면 재시험 또는 제한된 해석으로 남긴다. 동적 조건의 최대전력 기준은 시뮬레이션·PV 에뮬레이터 등 검증 가능한 경로가 있을 때 별도로 평가한다. 전체 일사량 변화와 구간별 부분음영 시험을 구분한다.

## 4. 데이터 기록

기록 주기는 **10 Hz를 초기 목표**로 하되 센서 갱신과 전송·저장 성능으로 검증한다. 이것이 MPPT 후보 평가나 PWM의 주기를 뜻하지 않는다. 화면 갱신과 독립적으로 측정·기록하며 중복된 오래된 측정값을 새 결과로 평가하지 않는다.

아래 항목은 CSV 스키마 초안이다. 구현 전 이름·단위·상태값을 고정한다.

| 항목 | 내용 |
| --- | --- |
| `run_id`, `sample_seq` | 시험 ID와 샘플 순번 |
| `t_s` | 시험 내 단조 증가 경과시간, 초 |
| `pv_voltage_v`, `pv_current_a`, `pv_power_w` | PV 측 측정값 |
| `out_voltage_v`, `out_current_a`, `out_power_w` | 출력 측 측정값 |
| `aux_voltage_v`, `aux_current_a`, `aux_power_w` | 보조전원 측 측정값 |
| `algorithm`, `state` | 수동·스윕·P&O·PSO·Hybrid와 대기·평가 등 실제 상태 |
| `duty_cmd` | 듀티 명령, 0–1 비율; 기준값 제어로 바뀌면 별도 필드·단위로 변경 |
| `servo_pan_cmd_deg`, `servo_tilt_cmd_deg` | 서보 명령 각도, 도 |
| `tracking_enabled`, `motor_moving` | 추적 활성 여부와 이동 명령 상태 |
| `shading_id` | 시험 조건표의 음영 ID |
| `pso_iteration`, `particle_id`, `restart_reason` | PSO 탐색과 재탐색의 추적 정보 |
| `record_valid`, `error_code` | 새 측정 여부·유효성·오류 |

세 센서가 완전히 동시에 변환한다고 가정하지 않는다. 갱신 시각·측정 나이가 중요하면 채널별 시각이나 유효 상태를 추가한다. 온도·일사량은 계측 장비를 확보했을 때만 실측값으로 추가한다. 확보하지 않은 항목은 추정값과 구분하거나 미측정으로 둔다.

파일과 시험 조건표를 함께 보관한다.

```text
data/raw/<run_id>.csv             원본 수신 데이터
data/processed/<run_id>_*.csv     정제·가공 데이터
docs/experiments/<run_id>.md      날짜·환경·배선·설정·이벤트·제외 사유
```

시험 조건표에는 코드 커밋, 부품·전원·부하, 패널·센서 식별, 제어 범위, 평가 간격, 초기값, 난수 시드, 기록 주기, 측정 경계와 파일을 연결한다. 누락을 원본에서 지우거나 장시간 미측정 구간을 임의 보간하지 않는다. 분석 처리와 제외 사유를 남긴다.

## 5. 평가 지표

| 지표 | 계산·정의 | 주의점 |
| --- | --- | --- |
| 누적 PV·출력 에너지 | 실제 측정 전력을 시간 적분 | 기동·탐색·전환 구간 포함 |
| 순에너지 | 확정한 경계의 출력 에너지에서 별도 보조 소비 차감 | 소비의 누락·이중 차감 방지 |
| 기준 최대점 대비 추출 비율 | 유효한 기준 최대전력 에너지 대비 PV 측 에너지 | 기준을 확보한 동일 조건·범위에서만 계산 |
| 변환 에너지 효율 | 동일 구간 `E_out / E_pv` | MPPT 추적 비율·패널 광전 효율과 구분 |
| 재추적 시간 | 조건 변화 후 사전 정의한 전력 수준을 유지할 때까지 | 시작 이벤트와 유지 완료 시각을 함께 기록 |
| 정상상태 변동 | 미리 정한 안정 구간의 전력 평균·표준편차 | 일사 변화·평균 출력도 함께 제시 |
| 탐색 비용·성공 | 탐색 시간, 평가 횟수, 에너지, 기준점 도달 여부 | 최대 반복·시간 초과·실패도 포함 |

재추적 성공의 **제안 기준**은 '유효한 새 기준 최대전력의 95% 이상을 2초 연속 유지'이다. 주 실험 전 계측 성능과 함께 검토해 확정하고, 결과를 본 뒤 유리하게 변경하지 않는다. 최초 도달 시각과 유지 확인 시각 중 어떤 값을 지표로 쓰는지도 확정한다.

양의 비교 기준 에너지가 충분할 때 개선율은 다음과 같이 계산한다.

$$
G_E=\frac{E_{test}-E_{baseline}}{E_{baseline}}\times100\%
$$

기준이 0에 가깝거나 순에너지가 음수이면 비율 해석을 제한하고 Wh 차이를 함께 제시한다. 최고값만 고르지 않고 반복 결과의 분포와 실패 수를 보고한다.

## 6. 시험 절차

### 단독 검증

1. 센서·전원·부하를 확인하고 기준 계측기와 비교한다.
2. 수동 제어로 명령 방향·한계·안정화 시간을 확인한다.
3. 서보를 고정한 상태에서 기준 곡선과 P&O를 확인한다.
4. 같은 조건에서 PSO를 반복하고 최적 후보의 재적용을 확인한다.
5. Hybrid 전환·재탐색을 확인한다.
6. 추적 장치를 별도로 시험하고 센서값 교란·소비를 확인한다.

### 본 비교

1. 실행할 A–D와 S0–S2의 유효 조합을 확정한다.
2. 관찰할 효과에 맞게 비교 쌍의 초기 운전점·시간·부하를 맞춘다.
3. 시험 ID·조건표·기록 경로를 준비하고 기록을 시작한다.
4. 정한 기동·음영 변경 절차로 실행한다. 명령과 실제 이벤트 시각을 구분한다.
5. 전 구간 CSV와 오류·재탐색 이벤트를 보관한다.
6. 초기화한 뒤 비교 순서를 바꿔 반복한다. PSO 난수 시드도 기록한다.
7. 기준 변화·누락·측정 오류를 표시하고 분석한다.

초기 반복 계획은 **확정한 조건당 5회 이상**을 제안하며, PSO 시작 조건·시드와 환경 변동을 검토해 주 실험 전에 횟수를 정한다. 이 횟수만으로 통계적 유의성이 보장되는 것은 아니다.

고정·추적의 비교에서는 하루 중 한 순간의 각도 변화만으로 장시간 추적 이득을 일반화하지 않는다. 동일 배열의 야외 순차 비교에는 날씨·태양 위치·온도 변화가 섞이므로 날짜·시간·관측 환경·순서 변경을 기록하고 가능한 결론 범위를 명시한다. 서로 다른 날의 최고값만 직접 비교하지 않는다.

## 7. 본 실험 전 확정할 사항

- 센서 오차와 측정 신뢰도를 판단할 기준.
- 운전 범위, 명령 변화량, 안정화·평균 평가 시간.
- 기록 누락 허용 범위와 무효 시험·실패 분류.
- 실제 다중 피크가 확인된 음영 시나리오.
- 기준 최대전력의 획득 방법과 유효 기간·운전 범위.
- 기동·동적 변화 시험의 길이, 재추적·정상상태 평가 구간.
- PSO 입자 수·반복·중지·재탐색 조건, 난수 시드 정책.
- 조건당 반복 횟수와 순서, 결과 처리 방법.
- 보조 소비 경계와 계측 범위.

## 8. 최종 증거와 결과물

원본 CSV, 조건표, 파라미터·코드 버전, 분석 코드, P–V 곡선, 시간별 전력·누적 에너지, 반복별 지표표를 남긴다. 성공뿐 아니라 실패·제외·음의 이득을 포함한다. 미계측·순차 비교·시뮬레이션 의존 등 한계를 보고서에 명시한다.

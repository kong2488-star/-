# 이중축 태양 추적 및 Hybrid MPPT 기반 태양광 발전 시스템

부분음영 환경에서 이중축 태양 추적과 PSO + P&O Hybrid MPPT를 결합해 실제 취득 에너지가 향상되는지 검증하는 캡스톤 프로젝트입니다.

## 연구 목표

- **태양 추적 효과:** 같은 MPPT 조건에서 고정형과 추적형의 취득 에너지를 비교합니다.
- **Hybrid MPPT 효과:** 같은 방향과 음영 조건에서 P&O와 PSO + P&O를 비교합니다.
- **통합 시스템 평가:** 탐색 중 손실과 모터·제어장치 소비를 포함해 순에너지를 평가합니다.

현재 구현 범위는 **P&O → PSO → PSO + P&O Hybrid**입니다.

## 시스템 개요

```text
[발전·측정]
태양광 패널 배열 → 입력 측정 → DC-DC 컨버터 → 출력 측정 → 부하
                     │                         │
                     └──────── ESP32 ──────────┘
                                  │
                            MPPT 제어 명령

[태양 추적]
LDR 4개 → ESP32 → 서보모터 2개 → 패널 방향 조절

[데이터 수집]
측정값·제어 상태 → ESP32 → 컴퓨터 → CSV → 분석
```

컨버터 제어 방식과 PC 연결 방식(USB 또는 Wi-Fi)은 부품 선정 및 단독 시험 후 확정합니다.
PSO 탐색 중에는 패널 각도 변경을 일시 중지하는 방식으로 통합을 검토합니다.

## 현재 진행 상태

**부품 구매 단계이며, 이 저장소에는 기본 문서와 폴더 구조만 준비되어 있습니다.**

| 구분 | 상태 |
| --- | --- |
| 태양광 패널 | 3 W × 3개 구매 |
| INA226 | 3개 구매 |
| 서보모터 | 2개 구매 |
| ESP32, LDR 5528, LDR용 저항, 바이패스 다이오드 | 구매 목록에 포함 |
| DC-DC 컨버터, 서보용 전원 | 구매 전 |
| 부하, 프레임, 계측 장비 | 구성·사용 가능 여부 확인 필요 |

패널 전압, 서보 모델, 센서 션트 저항, 핀 배치, PWM 설정, 허용 듀티는 아직 확정하지 않았습니다.

## 개발 순서

1. 부품 사양, 전원 경로, 측정 위치를 확인합니다.
2. ESP32에서 센서값을 읽고 PC에 기록합니다.
3. 컨버터 수동 제어와 무음영·부분음영 전력 곡선을 확인합니다.
4. P&O를 구현하고 기준 성능을 확보합니다.
5. PSO를 검증한 뒤 P&O와 결합합니다.
6. 이중축 추적을 검증하고 MPPT와 통합합니다.
7. 반복 비교 실험과 에너지 분석을 수행합니다.

첫 번째 목표는 **패널 한 개의 전압·전류·전력을 측정하고 CSV로 저장하는 것**입니다.

## 실험 원칙

- 추적 효과와 MPPT 효과를 구분해 비교합니다.
- 패널 방향, 부하, 초기 조건, 음영 위치와 정도를 기록합니다.
- 동일한 패널 3개 배열로 고정·추적 시험을 번갈아 수행할 경우 환경 변화와 시험 순서를 함께 기록합니다.
- 순간 최대전력뿐 아니라 누적 에너지, 재추적 시간, 정상상태 변동을 평가합니다.
- 기준 최대점은 실제 측정한 범위와 탐색 간격을 명시합니다.
- 발전·출력·보조 소비의 측정 경계를 정해 같은 소비를 두 번 차감하지 않습니다.
